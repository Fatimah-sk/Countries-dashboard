# 🌍 Countries Dashboard

An interactive web application for exploring countries and discovering information from around the world.

## ✨ Features
- Browse countries and their flags
- Search for countries
- View country details
- Fetch data from an external API

## 🛠️ Technologies
HTML • CSS • JavaScript • REST API
